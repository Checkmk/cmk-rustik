Run the OTel export loop forever.

Every export interval, the kubelet stats cache is collected into entities and sent to the OTel collector server. A failed export is logged and the cycle skipped; it never takes the rest of the process down.

Depends entirely on the kubelet stats cache in state and does effectively nothing if it is not yet populated.
